# Carpeta de Recursos Estáticos y Logos (Plataforma CCV 3.0)

Coloca en esta carpeta (`public/`) los archivos de imagen o logotipo que desees utilizar en la plataforma.

### Nombres sugeridos recomendados:
- `logo.svg` o `logo.png` -> Logo horizontal o logotipo principal institucional.
- `isotipo.svg` o `isotipo.png` -> Ícono / símbolo cuadrado (1:1) para el Sidebar flotante y favicons.
- `logo-white.svg` o `logo-white.png` -> Versión blanca/clara para fondos oscuros (Hero o Footer).

Cualquier archivo colocado aquí se sirve directamente desde la raíz web (ejemplo: `/logo.svg` o `/logo.png`).
