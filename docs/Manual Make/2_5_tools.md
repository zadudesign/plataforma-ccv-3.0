# 2.5. Tools

Tools are specialized built-in modules in Make used for advanced data manipulation, flow control, and structure transformation without requiring external API connections.

---

## 2.5.1. Aggregator

### What is an Aggregator?
An Aggregator merges multiple individual data bundles into a single bundle containing an array of items.

### How it Works
1. Accumulates all incoming bundles generated by a source module during a run.
2. Outputs 1 single bundle containing an array with one element per accumulated bundle.

### Key Settings
- **Source node**: Specifies the module whose output bundles should be aggregated.
- **Group by**: Optional formula evaluated for each bundle; produces one output bundle per distinct value.
- **Stop processing after an empty aggregation**: Prevents empty bundle execution if preceding filters block all data.
- *Examples*: Array aggregator, Text aggregator, Archive (ZIP) aggregator.

---

## 2.5.2. Iterator

### What is an Iterator?
An Iterator is the reverse of an Aggregator. It takes an array and splits it into a series of individual bundles.

### How it Works
- Accepts an array as input.
- Outputs each array element as an independent bundle, executing downstream modules once per element.
- Downstream modules can directly map fields from the individual array items.
- *Scope Note*: Outputs from modules located between an Iterator and an Aggregator are scoped and not accessible beyond the Aggregator module.

---

## 2.5.3. Router

### What is a Router?
A Router branches scenario execution flow into multiple separate module chains (routes).

### Key Rules and Features
- **Sequential Execution**: Routes process sequentially from top to bottom, not in parallel. Make completes the first route entirely before starting the second route.
- **Filters on Routes**: Each route can have its own filter conditions.
- **Fallback Route**: A route can be designated as a fallback route (marked with a special arrow icon). It executes only if the data did not pass through any other route filter.
- **Select Whole Branch**: Right-click or use route options to select, move, or edit all modules in a branch at once.
