# 2.6. Resources

Save time when building and editing scenarios in Make by using keyboard shortcuts.

---

## 2.6.1. Keyboard Shortcuts

| Action | Windows Shortcut | Mac Shortcut |
| :--- | :--- | :--- |
| **Zoom in** | `+` | `+` |
| **Zoom out** | `-` | `-` |
| **Save scenario** | `Ctrl + S` | `⌘ + S` |
| **Copy module** | `Ctrl + C` (on module) | `⌘ + C` (on module) |
| **Paste module** | `Ctrl + V` | `⌘ + V` |
| **Move all modules** | `Space + drag` (on module) | `Space + drag` (on module) |
| **Run once** | `Ctrl + Enter` | `⌘ + Enter` |
| **Create selection box (marquee)** | `Shift + drag` | `Shift + drag` |
| **Auto-align modules** | `Shift + A` | `⇧ + A` |
| **Run with existing data** | `Ctrl + Shift + Enter` | `⌘ + ⇧ + Enter` |
| **Undo change** | `Ctrl + Z` | `⌘ + Z` |
| **Redo change** | `Ctrl + Y` | `⌘ + Y` |
